📚 Tutorial

CodeForge Pro repariert deinen Code nicht. Du schreibst ihn selbst. Die Prüffunktion zeigt nur Fehler und Hinweise.

1 · HTML
Baue deine Spielseite mit Überschriften, Buttons, Bildern und anderen Elementen.
2 · CSS
Gestalte dein Spiel: Farben, Größen, Abstände und Positionen.
3 · JavaScript
Programmiere Regeln, Punkte, Gegner, Bewegung und alles, was dein Spiel tun soll.
4 · 🧪 Prüfen
CodeForge sucht unter anderem nach JavaScript-Syntaxfehlern und fehlenden HTML-Elementen.
5 · ▶ Start
Nur du entscheidest, wann dein Code ausgeführt wird.
6 · 💾 Speichern
Speichert dein Projekt lokal auf diesem Gerät.
