📚 CodeForge Tutorial

CodeForge verändert deinen Code nicht automatisch. Die Prüfung zeigt dir nur, wo ein Problem oder eine mögliche Verbesserung liegt.

1 · HTML – Aufbau
HTML bestimmt, was in deinem Spiel vorhanden ist. Nutze z. B. <h1>, <button> und <div>.
2 · CSS – Design
CSS macht dein Spiel schön: Farben, Größen, Abstände, Karten, Buttons und Positionen.
3 · JavaScript – Spielregeln
JavaScript macht dein Spiel lebendig: Punkte, Geld, Gegner, Käufe, Bewegung und Aktionen.
4 · 🧪 Prüfen
CodeForge prüft unter anderem HTML-Grundstruktur, Klammern, häufige JavaScript-Syntaxfehler und ob verwendete IDs im HTML vorhanden sind.
5 · ▶ Start
Nur wenn du Start drückst, wird dein Projekt ausgeführt. Bei einem erkannten JavaScript-Syntaxfehler wird die Vorschau nicht gestartet.
6 · 💾 Speichern
Speichert deinen aktuellen Code lokal auf diesem Gerät. Er wird nicht automatisch zu GitHub hochgeladen.
