📚 Tutorial

HTML

HTML beschreibt den Aufbau einer Website.

<h1>Hallo</h1> erzeugt eine Überschrift.

<p>Text</p> erzeugt einen Absatz.

<button>Klick</button> erzeugt einen Button.

CSS

CSS verändert das Aussehen deiner Website.

Zum Beispiel:

color: red;

Damit wird Text rot.

JavaScript

JavaScript macht deine Website interaktiv.

Zum Beispiel:

alert("Hallo");

Damit erscheint eine Meldung.
